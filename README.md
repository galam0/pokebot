# pokebot

PokeRogue 느낌의 포켓몬 디스코드 봇이에요. 스타팅 포켓몬 한 마리로 웨이브를 하나씩 넘어가고, 이길 때마다 보상을 골라요.

## 명령어
- `/스타팅` 지방과 스타팅 포켓몬을 골라 새 런 시작 (진행 중인 런이 있으면 그 화면을 보여줘요)
- `/이어하기` 진행 중인 런 화면을 다시 불러오기
- `/내포켓몬` 이번 런 포켓몬의 능력치·기술·다음에 배울 기술·진화
- `/기록` 내 최고 기록과 랭킹

## 규칙
- 100웨이브가 마지막 (마지막 보스는 전설 포켓몬), 10웨이브마다 보스와 새 지역(전체 회복)
- 실제 종족값·타입 상성·레벨업 기술·진화 레벨 사용 (PokeAPI 데이터)
- 급소, 명중률, 연속기, 흡수·반동, 랭크 변화, 마비·화상·독·얼음
- 이기면 HP 35% 회복, 보상: 상처약류, 이상한사탕, 비타민(이번 런 능력치 +10%), 학습장치

## 구조
- `game/engine.py` 배틀 엔진 (디스코드와 무관한 순수 파이썬)
- `game/pokedata.json.gz` 포켓몬 데이터 (`tools/build_data.py`로 PokeAPI CSV에서 생성)
- `storage.py` Neon Postgres 저장 (`DATABASE_URL`), `ui.py` 화면, `bot.py` 명령어·버튼
- `tools/simulate.py` 밸런스 시뮬레이션: `python tools/simulate.py 40`
