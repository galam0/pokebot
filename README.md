# pokebot

PokeRogue 느낌의 포켓몬 디스코드 봇이에요. 스타팅 포켓몬 한 마리로 웨이브를 하나씩 넘어가고, 이길 때마다 보상을 골라요.

## 명령어
- `/메뉴` 새 게임·데일리·주간 챌린지·이어하기·도감·기록·도움말 버튼 (본인에게만 보임)
- `/세팅` (관리자) 채널에 누구나 쓰는 게임 버튼 패널 올리기
- `/스타팅` `/데일리` `/챌린지` 바로 시작 (게임은 전용 스레드에서 진행)
- `/이어하기` 진행 중인 게임 다시 불러오기 · `/내포켓몬` 파티 · `/도감` · `/기록`

## 모드
- 일반: 지방별 스타팅 또는 도감에서 해금된 포켓몬(잡은 포켓몬의 첫 모습)으로 시작
- 데일리: 하루 한 번, 모두 같은 스타팅 후보·상대·보상·갈림길. 오늘의 랭킹
- 주간 챌린지: 주에 한 번, 규칙이 매주 바뀜 (단일 타입 / 아이템 금지 / 하드코어 / 레벨 제한). 주간 랭킹

## 규칙
- 100웨이브가 마지막 (마지막 보스는 전설 포켓몬), 10웨이브마다 보스와 새 지역(파티 전체 회복)
- 보스는 HP 보호막이 2~5칸, 한 번에 한 칸까지만 깎이고 칸이 깨질 때마다 능력치가 올라요
- 각 10웨이브 구간의 3·6웨이브 뒤 갈림길: 쉼터 / 강적의 길 / 떠돌이 상인 / 수상한 상자 / 수련장
- 파티 최대 6마리. 야생 포켓몬은 가방의 볼로 잡을 수 있어요 (보스는 잘 안 잡힘, 마스터볼은 100%)
- 이기면 살아 있는 파티 전원이 경험치를 얻고, 돈(₽)도 받아요
- 배틀 중 가방(볼·상처약·기력의조각)과 교체는 턴을 써요. 기절하면 다음 포켓몬을 골라요
- 웨이브마다 보상 1개 무료 + 돈으로 다시 뽑기 + 상점에서 아이템 구매
- 기술마다 PP가 있고, 모두 떨어지면 발버둥. 새 기술이 5번째면 잊을 기술을 직접 골라요
- 기술머신(보상)으로 그 포켓몬이 배울 수 있는 기술을 가르칠 수 있어요
- 진화: 레벨, 진화의 돌 등 진화 아이템, 연결의끈(통신 진화), 친밀도·시간 진화는 Lv.25
- 지닌 물건: 먹다남은음식, 조개껍질방울, 기합의띠, 생명의구슬, 구애머리띠/안경/스카프, 행복의알, 초점렌즈, 타입 강화 18종
- 가방: 볼 8종, 회복약·음료, 상태이상 치료제, 기력의조각/덩어리, 성스러운분말, PP 회복 4종, 포인트업/맥스, 배틀용 아이템
- 실제 종족값·타입 상성·레벨업 기술·기술머신·진화 방법 사용 (PokeAPI 데이터)

## 구조
- `game/engine.py` 배틀 엔진 (디스코드와 무관한 순수 파이썬)
- `game/pokedata.json.gz` 포켓몬 데이터 (`tools/build_data.py`로 PokeAPI CSV에서 생성)
- `game/scene.py` 게임풍 그림 (Pillow), `sprites.py` PokeAPI 스프라이트 캐시
- `storage.py` Neon Postgres 저장 (`DATABASE_URL`), `ui.py` 화면·버튼, `bot.py` 명령어·버튼 처리
- `tools/simulate.py` 밸게임스 시뮬레이션: `python tools/simulate.py 40`
