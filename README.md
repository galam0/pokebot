# pokebot

포켓몬 디스코드 봇이에요. 관동 → 성도 지방을 여행하며 배지를 모으고 챔피언에 도전하는 **모험**과,
PokeRogue처럼 웨이브를 넘어가는 **데일리·주간 챌린지**가 있어요.

## 명령어
- `/메뉴` 모험·데일리·주간 챌린지·이어하기·도감·기록·도움말·초기화 버튼 (본인에게만 보임)
- `/세팅` (관리자) 채널에 누구나 쓰는 게임 버튼 패널 올리기
- `/스타팅` 모험 시작 또는 이어서 · `/데일리` `/챌린지` 바로 시작 (게임은 전용 스레드에서 진행)
- `/초기화` 모험을 처음부터 (확인 버튼, 도감 기록은 남음)
- `/이어하기` 진행 중인 화면 다시 불러오기 · `/내포켓몬` 파티 · `/도감` · `/기록`

## 관동 모험
- 오박사 연구소에서 1~9세대 스타팅 27마리 중 하나를 고르고(지방 선택 메뉴), 라이벌 그린과 첫 배틀 (그린은 내 스타팅에 유리한 관동 스타팅)
- 40곳의 마을·도로·동굴·건물 (`game/kanto.py`). 🗺️ 이동하기로 연결된 곳에 가고, 배지가 모자라면 잠겨 있어요
- 🌿 풀숲 탐색: 그 장소의 야생 포켓몬(파이어레드·리프그린 기준)을 만나거나 아이템을 주워요
- ⚔️ 트레이너: 장소마다 한 번씩, 이기면 상금. 모두 이기면 선물을 주는 곳도 있어요 (너겟브릿지 등)
- 🏟️ 체육관 8곳 (웅·이슬·마티스·민화·독수·초련·강연·비주기): 체육관 트레이너 → 관장, 배지와 기술머신
- 배지 수마다 레벨 제한(말을 듣는 레벨)이 올라가요: 16 → 22 → 26 → 31 → 42 → 46 → 50 → 54 → 65 (관동 챔피언 후에는 성도 배지 기준)
- 🏆 석영고원: 사천왕 4명 + 챔피언 그린을 연달아 (방 사이에 가방으로 회복 가능)
- 라이벌 그린이 7번 등장, 전설(썬더·프리저·파이어, 챔피언 후 뮤츠·뮤)과 잠만보, 선물 포켓몬(이브이·라프라스)
- 모험의 전설은 포획률을 올려 둬서 잡을 만해요. 쓰러뜨리거나 도망쳐도 다시 만날 수 있어요
- 🏥 포켓몬센터에서 무료 회복. 파티가 모두 쓰러지면 돈을 잃고 마지막 센터로 (파이어레드 방식)
- 🛒 프렌들리숍은 배지 수에 따라 파는 물건이 늘고, 무지개시티 백화점은 영양제·진화의 돌·기술머신도 팔아요
- 💻 PC: 파티가 6마리면 잡은 포켓몬은 박스로. 센터에서 맡기기·데려오기
- 기술머신은 써도 없어지지 않아요. 영양제·이상한사탕은 가방에서 사용

## 성도 지방 (관동 챔피언 후)
- 석영고원 동쪽 26·27번도로 → 연두마을. 파티·PC·가방·돈을 그대로 데려가요 (`game/johto.py`, 29곳)
- 공박사에게 성도 스타팅(치코리타·브케인·리아코) 중 하나를 Lv.60으로 받아요
- 체육관 8곳(비상·호일·꼭두·유빈·사도·규리·류옹·이향), 라이벌 실버 5번, 로켓단(야돈의우물·라디오타워·아지트)
- 레벨이 높은 지방이에요: 야생 Lv.55~78(레벨에 맞게 진화한 모습), 레벨 제한 68 → 94, 성도 챔피언이 되면 제한 없음
- 성도 배지 8개면 석영고원에서 성도 리그(일목·독수·시바·카렌, 챔피언 목호)
- 전설: 라이코·앤테이·스이쿤(불탄탑), 칠색조(방울탑), 루기아(소용돌이섬), 빨간 갸라도스(분노의호수), 성도 챔피언 후 세레비(너도밤나무숲)

## 데일리·주간 챌린지 (웨이브 게임)
- 데일리: 하루 한 번, 모두 같은 스타팅 후보·상대·보상. 오늘의 랭킹
- 주간 챌린지: 주에 한 번, 규칙이 매주 바뀜 (단일 타입 / 아이템 금지 / 하드코어 / 레벨 제한). 주간 랭킹
- 100웨이브가 마지막, 10웨이브마다 보스(HP 보호막 2~5칸)와 새 지역(전체 회복)
- 웨이브마다 보상 1개 + 돈으로 다시 뽑기 + 상점

## 공통
- 실제 종족값·타입 상성·레벨업 기술·기술머신·진화 방법 (PokeAPI 데이터), PP, 상태이상, 급소, 지닌 물건
- 새 기술이 5번째면 잊을 기술을 직접 골라요. 진화: 레벨, 진화의 돌, 연결의끈(통신 진화), 친밀도·시간 진화는 Lv.25

## 구조
- `game/engine.py` 배틀 엔진 (디스코드와 무관한 순수 파이썬)
- `game/adventure.py` 모험 진행 (이동·탐색·트레이너·체육관·리그·센터·PC·상점), `game/kanto.py` 관동 데이터, `game/johto.py` 성도 데이터
- `game/pokedata.json.gz` 포켓몬 데이터 (`tools/build_data.py`로 PokeAPI CSV에서 생성)
- `game/scene.py` 게임풍 그림 (배틀·필드·관동 지도, Pillow), `sprites.py` PokeAPI 스프라이트 캐시
- `storage.py` Neon Postgres 저장 (`DATABASE_URL`), `ui.py` 화면·버튼, `bot.py` 명령어·버튼 처리
- 시뮬레이션: `python tools/sim_adventure.py 3 2` (모험 자동 플레이, 2 = 성도 챔피언까지), `python tools/simulate.py 40` (웨이브 게임)
