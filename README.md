# pokebot

포켓몬 디스코드 봇이에요. 관동 → 성도 지방을 여행하며 배지를 모으고 챔피언에 도전하는 **모험**과,
PokeRogue처럼 웨이브를 넘어가는 **데일리·주간 챌린지**가 있어요.

## 명령어
- `/메뉴` 내 진행 상황이 담긴 메뉴 카드 그림 + 모험·데일리·주간 챌린지·이어하기·도감·기록·도움말·초기화 버튼 (본인에게만 보임)
- `/세팅` (관리자) 채널에 누구나 쓰는 게임 버튼 패널 올리기
- `/스타팅` 모험 시작 또는 이어서 · `/데일리` `/챌린지` 바로 시작 (게임은 전용 스레드에서 진행)
- `/초기화` 모험을 처음부터 (확인 버튼, 도감 기록은 남음)
- `/이어하기` 진행 중인 화면 다시 불러오기 · `/내포켓몬` 파티 · `/기록`
- `/도감` 그림 도감: 세대별로 한 쪽에 24마리, 못 잡은 포켓몬은 ?로 표시 (세대 선택·쪽 넘기기)
- `/주인공` 모험 주인공 바꾸기 (1~9세대 역대 주인공 20명)
- `/도움말` 주제별 도움말 (시작하기·명령어·모험·배틀·성장·지방·데일리)

## 화면
- 포켓몬 그림은 1~9세대 모두 **블랙·화이트 도트 스타일** (smogon/sprites, `tools/build_sprite_names.py` → `game/sprite_names.json`),
  PC·도감 같은 작은 칸은 같은 스타일의 메뉴 아이콘. 도트가 깨지지 않게 정수배로만 키워요
- 배틀 화면은 **GIF**: 1~5세대는 블랙·화이트처럼 움직이고, 6세대부터는 통통 뛰어요 (기술 연출은 없음)
- 관동 필드는 **파이어레드 원본 맵** 위에 주인공이 서 있는 장면 (장소 팻말 + 대화창). 마을은 센터 문 앞, 센터에서 쉬면 간호순 앞,
  숍은 점원 앞, 체육관에 도전하면 관장 앞. 성도·호연은 그린 배경
- 트레이너·관장·사천왕·라이벌과 싸우기 전에 **상대가 나와서 대사를 해요** (⚔️ 승부! 버튼을 누르면 포켓몬이 나와요).
  관동·호연은 파이어레드·에메랄드 트레이너 그림, 성도의 관장·사천왕·라이벌은 하트골드 그림 (`tools/build_trainer_pics.py`)
- PC는 파이어레드 박스 화면 (숲 배경지에 박스 포켓몬, 왼쪽에 지금 파티)
- 레드·리프·휘웅·봄이 말고 다른 주인공은 맵에서 레드(남)·리프(여) 모습으로 걸어요

## 관동 모험
- 오박사 연구소: 설명 그림 → 주인공 고르기(레드·리프부터 플로리안·줄리아나까지 20명) → 스타팅 고르기(1~9세대 27마리, 지방 메뉴로 3마리씩 그림 한 장에), 라이벌 그린과 첫 배틀 (그린은 내 스타팅에 유리한 관동 스타팅)
- 40곳의 마을·도로·동굴·건물 (`game/kanto.py`). 🗺️ 이동하기로 연결된 곳에 가고, 배지가 모자라면 잠겨 있어요
- 🌿 풀숲 탐색: 그 장소의 야생 포켓몬(파이어레드·리프그린 기준)을 만나거나 아이템을 주워요
- ⚔️ 트레이너: 장소마다 한 번씩, 이기면 상금. 모두 이기면 선물을 주는 곳도 있어요 (너겟브릿지 등)
- 🏟️ 체육관 8곳 (웅·이슬·마티스·민화·독수·초련·강연·비주기): 체육관 트레이너 → 관장, 배지와 기술머신
- 배지 수마다 레벨 제한(말을 듣는 레벨)이 올라가요: 16 → 22 → 26 → 31 → 42 → 46 → 50 → 54 → 65 (관동 챔피언 후에는 성도 배지 기준)
- 🏆 석영고원: 사천왕 4명 + 챔피언 그린을 연달아 (방 사이에 가방으로 회복 가능)
- 라이벌 그린이 7번 등장, 전설(썬더·프리저·파이어, 챔피언 후 뮤츠·뮤)과 잠만보, 선물 포켓몬(이브이·라프라스)
- 모험의 전설은 포획률을 올려 둬서 잡을 만해요. 쓰러뜨리거나 도망쳐도 다시 만날 수 있어요
- 🏥 포켓몬센터에서 무료 회복. 파티가 모두 쓰러지면 돈을 잃고 마지막 센터로 (파이어레드 방식)
- 🛒 프렌들리숍은 배지 수에 따라 파는 물건이 늘고, 무지개시티 백화점은 영양제·진화의 돌·기술머신도 팔아요
- 💻 PC: 파티가 6마리면 잡은 포켓몬은 박스로. 센터에서 맡기기·데려오기
- 기술머신은 써도 없어지지 않아요. 영양제·이상한사탕은 가방에서 사용

## 지방 이동과 레벨
- 새 지방에 처음 들어가면 파티·PC 포켓몬의 레벨이 **Lv.8**로 맞춰져요 (진화·기술·지닌 물건은 그대로). 가방·돈은 유지
- 레벨 제한은 지금 키우는 지방(아직 챔피언이 안 된 첫 지방)의 배지 수로 정해져요

## 성도 지방 (관동 챔피언 후)
- 석영고원 동쪽 26·27번도로 → 연두마을 (`game/johto.py`, 29곳). 금·은 레벨 (체육관 9~40, 리그 40~50)
- 공박사에게 성도 스타팅(치코리타·브케인·리아코) 중 하나를 Lv.5로 받아요
- 체육관 8곳(비상·호일·꼭두·유빈·사도·규리·류옹·이향), 라이벌 실버 5번, 로켓단(야돈의우물·라디오타워·아지트)
- 레벨 제한 12 → 52, 야생은 레벨에 맞게 진화한 모습으로 나와요
- 성도 배지 8개면 석영고원에서 성도 리그(일목·독수·시바·카렌, 챔피언 목호)
- 전설: 라이코·앤테이·스이쿤(불탄탑), 칠색조(방울탑), 루기아(소용돌이섬), 빨간 갸라도스(분노의호수), 성도 챔피언 후 세레비(너도밤나무숲)

## 호연 지방 (성도 챔피언 후)
- 담청시티 항구 → 연락선 타이드호 → 미로마을 (`game/hoenn.py`, 31곳). 루비·사파이어 레벨 (체육관 12~43, 리그 46~58)
- 털보박사에게 호연 스타팅(나무지기·아차모·물짱이) 중 하나, 라이벌 봄이 4번, 마그마단·아쿠아단
- 체육관 8곳(원규·철구·암페어·민지·종길·은송·풍&란·아단), 그랜드시티에서 호연 리그(혁진·회연·미혜·권수, 챔피언 성호)
- 전설: 가이오가·그란돈(각성의 사당), 레쿠쟈(하늘기둥), 챔피언 후 레지락·레지아이스·레지스틸·라티아스·라티오스(고대 석실)
- 호연 챔피언이 되면 레벨 제한이 없어져요

## 데일리·주간 챌린지 (웨이브 게임)
- 데일리: 하루 한 번, 모두 같은 스타팅 후보·상대·보상. 오늘의 랭킹
- 주간 챌린지: 주에 한 번, 규칙이 매주 바뀜 (단일 타입 / 아이템 금지 / 하드코어 / 레벨 제한). 주간 랭킹
- 100웨이브가 마지막, 10웨이브마다 보스(HP 보호막 2~5칸)와 새 지역(전체 회복)
- 웨이브마다 보상 1개 + 돈으로 다시 뽑기 + 상점

## 공통
- 실제 종족값·타입 상성·레벨업 기술·기술머신·진화 방법 (PokeAPI 데이터), PP, 상태이상, 급소, 지닌 물건
- 모험: 상대와 싸운 포켓몬(한 번이라도 나와 있던 포켓몬)만 경험치를 받아요 (기절하면 못 받음). 배틀은 파티 맨 앞 포켓몬부터.
  배틀이 끝나면 포켓몬마다 얻은 경험치·레벨 변화 화면
- 새 기술이 5번째면 잊을 기술을 직접 골라요. 진화: 레벨, 진화의 돌, 연결의끈(통신 진화), 친밀도·시간 진화는 Lv.25

## 구조
- `game/engine.py` 배틀 엔진 (디스코드와 무관한 순수 파이썬)
- `game/adventure.py` 모험 진행 (이동·탐색·트레이너·체육관·리그·센터·PC·상점), `game/kanto.py` 관동 데이터, `game/johto.py` 성도, `game/hoenn.py` 호연 데이터
- `game/pokedata.json.gz` 포켓몬 데이터 (`tools/build_data.py`로 PokeAPI CSV에서 생성)
- `game/scene.py` 게임풍 그림 (배틀 GIF·필드·관동 지도, Pillow), `sprites.py` PokeAPI 스프라이트 캐시
- `assets/maps/` 파이어레드 맵 (`tools/render_maps.py`), `assets/maps/places.json`·`assets/people/`·`assets/pc/` (`tools/build_places.py`)
- `game/heroes.py` 주인공 목록, `assets/trainers/` 주인공 그림 (smogon/sprites, 6·8·9세대는 쇼다운에서 받음)
- `storage.py` Neon Postgres 저장 (`DATABASE_URL`), `ui.py` 화면·버튼, `bot.py` 명령어·버튼 처리
- 시뮬레이션: `python tools/sim_adventure.py 3 2` (모험 자동 플레이, 1·2·3 = 관동·성도·호연 챔피언까지), `python tools/simulate.py 40` (웨이브 게임)
